# contextwell-tools

Filesystem/code tooling domain for copilot-fusion, including search, structured extraction, deterministic text compaction, extractive summarization with optional entities, guarded text patch editing with structured previews, Tree-sitter symbol lookup with references and caller/callee callgraphs (Python/JS/TS/JSX/TSX/Go; see `symbols.py`), and opt-in allowlisted terminal execution.
